## Zusammenfassung

### Problem
Wie speichert man mehr als einen Wert in einer Variable?

### Lösung
Mit einer Liste kann eine Variable 0 bis n Werte in fester Reihenfolge halten.

### Ergebnis
Die Arbeit mit großen Datensätzen wird möglich
