## Overview
> Conditions are executed once at most, loops possibly multiple times.

## Conditions
### Python
```python
if sunUp:
    print ("Hallo Sonne!")
if onEarth:
    print ("Hello World")
else:
    print ("Hello Aliens")
```

## Loops
### Python
```python
for x in range(10):
    print (x)
while (sunUp):
    print ("A day without sunshine, is, you know, night.)
```
